# Talos torpedo / marker launcher V10 — 3D viewer

Interactive web view of the OSU Talos (RoboSub) launcher V10, a native SolidWorks rebuild: torpedo body, marker base,
top cover, crossbar arm, pushing arm, modified servo holder and Bottom Cover, D18 torpedoes and all-PETG P83 markers,
on the robot's crossbars. Captive nuts throughout (no heat-set inserts).

Live: https://zehdari.github.io/talos-launcher-viewer/

Static three.js page (`index.html`) loading glTF models exported from the SolidWorks assembly. CAD checked in
SolidWorks (mates, interference, motion); not yet printed or pool-tested.
